# Research-Proposal-Preparation

A simple static website for an academic course platform concept focused on **Research Proposal Preparation**.

## Files
- `index.html`: page structure and course sections.
- `styles.css`: visual styling.
- `script.js`: enrollment form interaction.

## Run locally
Open `index.html` directly in a browser, or use a static server:

```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
